# Jumpit

Jumpit is an original mobile-first storybook platform game for kids. Run, jump,
find lantern seeds, and carry light through five grounded places.

Version 1.8 opens all 20 trails across Garden Walk, Rooftop Rain, Workshop Loft,
Lantern Market, and Beacon Keep. Its First Light pass makes the opening trail a short,
zero-fall run-jump-stomp lesson, keeps the hardest tower forgiving, and reduces the fresh
home screen to one obvious play action. One shared fixed-step transition powers live play
and deterministic level replays. The v1.8 offline cache stays immutable while a complete
replacement installs, and advanced daily or friend challenges remain separate from campaign
progress under More.

The gameplay borrows genre verbs, not somebody else's identity. Jumpit contains
no Nintendo characters, names, art, music, sounds, trade dress, or copied maps.

> no ads, no lives, no timers, nothing to buy, no accounts, no cookies, nothing sold or shared.

## Local

```sh
npm install
npm run serve
npm test
npm run test:e2e
npm run build
```

The release history begins at `v0.0.0` and advances only when the corresponding
verified increment is real. The full roadmap and acceptance evidence live in
